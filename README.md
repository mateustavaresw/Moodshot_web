**A câmera que sente o momento.**

Moodshot é uma aplicação de câmera fictícia que sugere modos de captura de acordo com o "mood" do momento — Alegria, Calma, Intensidade, Natureza, Nostalgia. Projeto acadêmico (Sprint 3 — Web Development), migrado de HTML/CSS/JS puro para React.
